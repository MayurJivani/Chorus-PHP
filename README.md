The original Chorus: a Wordle-style music guessing game in PHP and vanilla
JavaScript. Log in with Spotify, pick Billboard's Top 100 or an artist's
discography, hear a three-second snippet, and name the track.

**This version is no longer developed.** The current one is
[Chorus](https://github.com/MayurJivani/Chorus), playable at
[chorusify.com](https://chorusify.com).

[Demo video](https://drive.google.com/file/d/1wddugDO1Hbh3EKOz944R5epaJv6EXRFF/view?usp=sharing)

## What it does

- Spotify login, so the game knows what you actually listen to
- Play the latest hits, or go deep on one artist's discography
- A random track per round from the chosen pool
- Three-second snippets, typed guesses, and a score that tracks your run

## Dependency

`jwilsson/spotify-web-api-php`
